# sam-flash
I wanted another OS on my tablet. This is how I failed.

## What is this?
This is the story of me trying to de-google my personal electronics and wanting to use anything other than android on my Galaxy Tab A8.

I wasn't big into android programming / close hardware programming at all. I did some very light x86 (you can find that one on my profile, it's a work in progress!) but I'm a "hands-on" kinda guy and learning by doing is the best thing you can do I guess.

Spoiler: It didn't work. I'm not entirely sure why but my best guess is that LineageOS doesn't work on the SM-X200 because of the UNISOC chip, but I don't really know to be honest. Any help is appreciated!

So I decided to use the tablet as a terminal server with Termux on it. What am I gonna do with Termux? I don't know yet! This "project" is gonna be an on / off thing.

## Project structure
- apks: APKs I used during the course of this miserable journey. This is just a list, I'm not uploading whole APK files to GitHub
- programs: any "helper" programs that saved my life and some explaining
- scripts: Here is what I wrote myself to either help me (```cleanUp-tablet.sh```) or other scripts that are doing anything and everything
